Prompts

This directory documents the prompt templates used by the study-version collaborative diary-agent prototype.

The prototype used prompt templates for three main LLM operations:

1. generation of an initial diary-post draft;
2. revision of the diary post in response to user input; and
3. generation of the diary agent's conversational follow-up response.

The initial-generation prompt was supplied by the direction of the diary entry (past or future), the dialogue type, the user's stated purpose, recent activity information, and selected baseline information.

The materials in this directory document the prompts used in the study-version prototype and are provided for research transparency.
